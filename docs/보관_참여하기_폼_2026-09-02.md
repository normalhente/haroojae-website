# 보관 — '참여하기' 폼 마크업 (2026-09-02 제거)

## 왜 뺐나

`#forms` 섹션에 폼이 둘 있었다(독자 후기 / 번역 원서 요청). **둘 다 받는 곳이 없었다.**
제출 핸들러가 `preventDefault()` 후 "접수되었습니다"를 띄우고 폼을 비우는 게 전부라,
사용자가 쓴 글이 그대로 사라졌다. 접수됐다고 말만 하고 버리는 상태였다.

네이버폼 연결도 검토했으나 불가능하다 — form.naver.com 응답 페이지는 2.3KB 껍데기이고
`<form>`·`input`·`action` 이 없다. 전부 JS 로 그려지고 제출도 내부 토큰을 거친다.
외부 폼에서 값을 넘기거나 미리 채우는 공개 방법이 없다(구글폼과 다르다).

그래서 폼을 걷어내고 **메일·인스타그램 안내**로 바꿨다. 폼의 항목들은 버리지 않고
`mailto:` 본문 서식으로 옮겨, 받는 쪽에서 같은 정보를 받는다.

## 되살리려면

1. 아래 마크업을 `#forms` 섹션의 `.forms-grid` 안에 되돌린다
2. JS 핸들러를 되돌린다 — **단, 받는 곳을 먼저 정할 것.** 그러지 않으면 같은 문제가 재발한다
   - Formspree 등을 쓰면 `<form action="...">` 만 붙이면 지금 마크업 그대로 동작한다
   - 네이버폼이면 폼이 아니라 버튼으로 가야 한다
3. i18n 항목을 되돌린다
4. `.form-grid` · `.form-group` · `.form-submit` · `.form-success` CSS 는 **지우지 않았다**.
   그대로 두었으니 마크업만 되돌리면 스타일이 붙는다

되돌릴 커밋: `62fece7` (이 파일을 만든 커밋의 직전)

## 2. JS 핸들러

```js
    // 후기 폼의 '읽은 책' 목록을 도서 카드에서 만든다. 책이 늘면 여기 손댈 필요가 없다.
    // '기타'는 항상 맨 끝에 둔다.
    (function fillReviewBooks() {
      const sel = document.getElementById('reviewBook');
      if (!sel) return;
      const etc = sel.querySelector('option[value="기타"]');
      const titles = [...document.querySelectorAll('#booksGrid .book-card')]
        .map(c => (c.dataset.title || '').trim()).filter(Boolean);
      titles.forEach(t => {
        const o = document.createElement('option');
        o.value = t; o.textContent = t;
        sel.insertBefore(o, etc);
      });
    })();

    document.getElementById('reviewForm')?.addEventListener('submit', function(e) {
      e.preventDefault();
      const s = document.getElementById('reviewSuccess');
      if (s) s.style.display = 'block';
      this.reset();
    });
```
