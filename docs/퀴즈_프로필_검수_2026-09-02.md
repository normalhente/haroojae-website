### ⑤ 프로필이 완전히 같은 두 책

- **세로 토레**와 **THE TOWER — 더 타워**: `rock/explore · mystery · tension · 수준 3` 으로 동일. 같은 산(세로 토레) 이야기라 자연스럽긴 하지만, **둘은 항상 동점**이라 어느 쪽이 나올지는 난수가 정한다. 하나를 갈라주고 싶으면 수준이나 분위기를 다르게.

## 판단할 것 (설계)

1. **테마를 우선시킬까?** — 지금은 테마 3 / 형식 3 / 분위기 2 / 수준 0~2. 테마를 4~5로 올리거나, '테마 맞는 책이 하나라도 있으면 그중에서만 1위'로 바꾸면 ②가 사라진다. 대신 테마당 책이 적은 조합은 선택 폭이 준다.
2. **동점을 줄일까?** — 가중치를 3/3/2/2 → 5/3/2/2 처럼 벌리면 동점이 준다. 재보고 정할 수 있다.
3. **페르소나·이유 문구** — 별도로.
