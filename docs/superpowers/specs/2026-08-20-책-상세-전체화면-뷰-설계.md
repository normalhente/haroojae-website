# 책 상세 전체화면 뷰 — 설계

2026-08-20 · 하루재클럽 웹사이트(`index.html` 단일 파일)

## 배경

책 소개가 지금은 **페이지가 아니라 모달**이다(카드 클릭 → `data-*` 읽어 팝업).
사장님 요청은 "책을 더 크게, 3D 목업처럼" — 안그라픽스(agbook.co.kr) 책 페이지가 참고 대상이다.

지난 세션에서 여기까지 와 있다(커밋 `95a2fd4`, 미배포):

- `#bookDetail` 전체화면 뷰의 **마크업과 CSS가 이미 들어와 있다**. 다만 숨김 상태
- `openDetail()` / `closeDetail()` **JS가 없다**. `←목록으로` 버튼은 지금 누르면 에러가 난다
- 42권 중 **25권**에 실사 3D 목업이 붙었다(`data-mockup`). 나머지 17권은 없다

이 문서는 그 절반을 마저 잇는 설계다.

## 결정 사항

| 항목 | 결정 | 이유 |
|---|---|---|
| 기존 모달 | **제거하고 상세 뷰로 완전 대체** | 같은 내용을 두 곳에서 관리하지 않는다. 책마다 동작이 달라 사용자가 헷갈리는 것도 막는다 |
| URL | **해시 라우팅** `#book/<슬러그>` | 단일 index.html 유지. 뒤로가기·새로고침·링크 공유가 된다. 검색 색인은 안 되지만, 그건 실제 파일이 있어야만 되는 것이라 별도 과제로 남긴다 |
| 목업 없는 17권 | ~~CSS 3D 책으로 폴백~~ → **평면 표지**(구현에서 변경, 3장 참조) | 상세 화면은 표지를 크게 보여주는 자리다. 3D 로 세우면 표지가 기울어 제목이 읽히지 않는다 |

**범위 밖**(이번에 하지 않는다): 이전/다음 책 이동, 실제 다중 페이지(`books/01.html`) 생성,
17권 목업 신규 제작.

## 1. 지울 것과 남길 것

지운다:

- `#bookModal` 마크업 (index.html 2407~2446)
- `.modal-overlay` · `.modal-box` · `.modal-close` CSS (742~902, 1708~1715 모바일 분기)
- 모달 열기 핸들러 · `closeModal()` · `closeModalBtn()`

⚠️ **`.modal-*` 을 싸잡아 지우면 안 된다.** 새 상세 뷰 마크업이 아래를 **그대로 재사용**한다:

```
.modal-lang  .modal-author  .modal-meta  .modal-divider  .modal-desc
.modal-quote  .modal-author-bio  .modal-tags  .modal-buy-wrap  .modal-buy-btn
.modal-cover-noimg  .modal-cover-title  .award-badge  .book3d  .book3d-front  .book3d-spine
```

지우는 것은 **바깥 껍데기 클래스 3개뿐**이다.

## 2. 라우팅

`location.hash` 를 **단일 진실원**으로 둔다. 클릭이 뷰를 직접 열지 않는다.

```
카드 클릭 → location.hash = '#book/<슬러그>'
                              ↓
                        hashchange
                              ↓
              해시 있음 → openDetail(card) / 없음 → closeDetail()
```

이렇게 하면 뒤로가기·직접 링크·프로그램 호출(퀴즈)이 전부 같은 한 경로를 탄다.

- **슬러그**: 제목에서 공백을 `-` 로. `세로 토레` → `#book/세로-토레`.
  42권 슬러그가 유일한지는 구현 중에 실측 확인한다. 충돌하면 번호(`data-img` 의 `NN-`)를 붙인다
- **직접 진입**: 로드 시 해시를 한 번 파싱해 해당 카드를 찾아 연다. 카드가 없으면 해시를 지우고 목록으로
- **닫기**: 우리가 밀어 넣은 항목이면 `history.back()`, 아니면 해시만 제거(`replaceState`).
  직접 링크로 들어온 사람이 닫았을 때 사이트 밖으로 튕기지 않게 하려는 것
- **ESC**: 지금 모달을 닫던 keydown 핸들러를 상세 뷰 닫기로 돌린다

`.book-detail` 이 `position:fixed; inset:0` 이라 **목록은 뒤에 그대로 살아 있다**.
따라서 스크롤 위치 복원은 공짜다 — `body` 스크롤 잠금/해제만 하면 된다.

## 3. 표지 3갈래

```
data-mockup 있음  → 실사 목업 <img id="bdMockup">   (25권)
없고 data-img 있음 → 평면 표지 <img id="bdFlat">     (17권)
둘 다 없음        → 제목 박스 #bdNoImg              (0권 — 42권 모두 표지가 있다)
```

> **구현에서 바뀐 것**: 설계 때는 목업 없는 17권에 CSS 3D 책을 세우려 했으나,
> 실제로는 **평면 표지**로 갔다. 상세 화면은 표지를 크게 보여주는 자리인데
> 3D 로 세우면 표지가 기울어 제목이 읽히지 않는다. 목업이 있는 책은 사진 그대로,
> 없는 책은 평면으로 두는 편이 표지 정보를 해치지 않는다.
> 따라서 아래 3장의 `sizeBook()` 관련 논의는 **적용되지 않았다** — 평면 표지는
> 비율을 이미지가 스스로 정하므로 크기 계산이 필요 없다.

### 고쳐야 할 것 두 가지

**(1) `sizeBook()` 이 모달 전용이다.** 현재 `modalImg`/`modalBook`/`modalCover` id 가
하드코딩돼 있어(index.html 3061) 상세 뷰에서 동작하지 않는다.
→ **인자로 요소를 받도록 바꿔** 양쪽이 같은 함수를 쓰게 한다.

이때 안에 든 두 가지 교훈은 **반드시 보존한다**:

- 캐시된 이미지는 `img.complete` 가 즉시 true → 배치 전에 불려 `clientWidth = 0` 이 된다.
  `requestAnimationFrame` 재시도(최대 12회) 유지
- 모바일 판정은 패널 폭이 아니라 **뷰포트**(`window.innerWidth <= 768`)로

**(2) 높이가 서로를 참조하는 순환.** `.bd-cover` 는 `min-height:420px` 인데
3D 책 크기를 `box.clientHeight` 로 계산한다. 책 높이가 박스 높이를 정하고 박스 높이가 다시
책 높이를 정하는 꼴이라 값이 안 잡힌다.
→ `.bd-cover` 에 데스크톱 `min-height: 70vh` 를 줘서 목업(`max-height:70vh`)과 기준을 맞춘다.

## 4. 퀴즈 연결

퀴즈 결과에서 책 보기가 지금 `#books` 로 스크롤한 뒤 **800ms 기다렸다가** `card.click()` 이다
(index.html 3425). 전체화면이 덮을 거라 스크롤이 무의미해진다.
→ 해시만 바꾸도록 단순화한다.
